📌 Breve descripción del proyecto
Este proyecto es una aplicación web construida con Streamlit, Pandas y Plotly que permite analizar un conjunto de datos de vehículos usados en Estados Unidos. La aplicación carga la información desde un archivo CSV y ofrece visualizaciones interactivas para explorar las características de los coches.

📌 Para qué sirve la aplicación web
La aplicación sirve para explorar y comprender patrones en los datos de vehículos. Permite observar cómo se distribuyen los valores del odómetro (kilometraje) y cómo se relacionan con el precio de los coches. Es una herramienta sencilla para análisis exploratorio de datos, útil en contextos de aprendizaje o investigación.

📌 Qué tipo de funcionalidad proporciona
Visualización de histogramas: muestra la distribución del kilometraje de los vehículos.

Gráfico de dispersión: permite ver la relación entre el kilometraje y el precio.

Interactividad: el usuario decide qué gráfico mostrar mediante botones, lo que hace que la experiencia sea dinámica y fácil de usar.
